## Offband Meshcore 1.2.2

A follow-up to 1.2.1 that brings back desktop history left behind in other databases.

### Fixed

- **Desktop (Windows/Linux): message history split across older databases is now
  reunited.** 1.2.1 pinned the database to one location but only carried over a
  single prior copy. If you had run several differently-built copies of the app,
  some history could still be sitting in other database files. On launch, Offband
  now finds those stores and merges them into the pinned database (messages by id,
  contacts by public key), so history that looked missing comes back. Your old
  databases are never deleted, and a run that hits a problem leaves every source
  untouched and retries next launch. Android, web, and macOS were not affected
  (#367, #370).
