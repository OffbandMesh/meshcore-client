## Offband Meshcore 1.5.0-beta.1

First beta of the 1.5.0 line, for the closed test track. This is a testing build,
so features here are still being proven. Bug reports are what make the production
releases solid.

### New to test

- **Experimental section.** A hidden **7-tap on the Build row** in settings unlocks
  an Experimental area. Turning the section off again clears every experimental
  toggle (#509, #553).
- **OKIMesh CoreScope (Experimental).** See how many **OKIMesh CoreScope** observers
  heard each packet: an observer / observations badge with adaptive polling and tap
  or long-press to refresh (#549, #550). This is tied specifically to OKIMesh's
  CoreScope service, not a generic or self-hosted backend.
  - **Heads-up:** it needs a **forthcoming Offband firmware** (0xC6 support, firmware
    ver code 22 or newer, tracked in #611) that is **not yet available for download**.
    Until you are on that firmware it stays inert. This is here so it is ready to test
    the moment the firmware ships.
- **About screen.** About now lives in its own Settings category, with links out to
  the website, the Play listing, and the donate page (#526, #527).

### Fixed

- **Repeater CLI** is steadier: late replies are surfaced instead of dropped,
  commands have their own timeout budget, the reported timeout window matches what
  was actually armed, and a prefixed reply only completes the command that owns the
  prefix (#528, #529, #531, #532, #533).
- **Broker import** never flips the broker enabled state, and a blank-field GET no
  longer leaks the echoed key line (#469, #470).
- **Channel "Send Again"** is gated correctly on the repeat count (#555).

Thanks for testing. If something acts weird, that is exactly what this track is for,
and your reports keep production solid for everyone.
