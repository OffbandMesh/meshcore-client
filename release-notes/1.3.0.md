## Offband Meshcore 1.3.0

Our biggest feature release since the 1.2.0 redesign, and the first Offband build
on the Google Play production track. Reactions that work across MeshCore clients,
one-tap Observer config sharing, log and serial capture you can export, a cleaned-up
Settings screen, richer path diagnostics, and a solid batch of reliability fixes.

### Reactions that carry names

Incoming reactions now show **who** reacted, not just a count. Emoji reactions from
PocketMesh and MeshCore One are read and displayed properly instead of arriving as
raw token text, so a reaction from someone on another client just works (#383, #380).

### Observer config profiles

Set up an Observer the easy way. **Import a config profile** from the shared catalog
or a URL, see a **field-by-field diff** against what the radio has now, and apply it,
all from Observer settings. Profiles use a simple YAML schema, and imports are always
fetched fresh so you never apply a stale copy (#404, #405, #406, #407, #402, #403).

### Export your logs, capture the serial

The App log and BLE log now have a **Share** action: Save As on desktop, download on
web, share sheet on mobile. There is also a new **serial / boot-log capture** screen
under Debug, with a Reboot Device action so you can grab a clean boot log, download it
in chunks, and watch capture status live (#393, #433, #430).

### Richer path diagnostics

The message Path screen now shows the **path type**, plus **per-message SNR and RSSI**
pulled from the radio's RX fields, so you can see link quality hop by hop. Device Info
also reports the exact build it is running and the active radio data scope
(#438, #439, #397).

### A tidier Settings screen

Settings categories were reordered and renamed in plain language, Observer moved up,
debug logging moved into its own Debug category, per-channel notification mode is on
the channel menu, and there is a new keep-screen-awake option
(#271, #273, #274, #275, #269, #270).

### Reliability

- Sending a **max-length message no longer wedges** your outbox: the size cap is
  MTU-aware and a failed write recovers instead of stalling every later send (#395).
- **Channel changes push live** and debounce, so a burst of edits is one re-sync,
  not many (#429).
- A **storage-init failure now surfaces** a clear warning instead of failing quietly
  (#385).
- **Desktop builds run on a clean machine** (Windows and Linux) with their native
  libraries bundled (#445).
- **Battery-optimization guidance** on Android so background delivery is not silently
  killed (#443).
- Back-button behavior refined so Back never drops you off a connected radio
  (#389, #390).

### Your desktop history, reunited

On Windows and Linux, message history that ended up **split across several older
database files** is now brought back together automatically on launch, merged into
one database with your original files left untouched. This completes the desktop
storage work: the database is pinned to one fixed location, and anything stranded in
a separate file is pulled back in (#367, #370).

### Thank you

Offband Meshcore is now approved for Google Play production, and this is the first
official public release: open to everyone, with no tester list and no sideloading. It
exists because of the OKIMesh community (https://okimesh.org/), who brought ideas,
