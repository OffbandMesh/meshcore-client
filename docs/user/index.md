# Offband MeshCore app manual

Offband MeshCore is an open-source app for MeshCore LoRa radios. It connects to
your radio over Bluetooth, USB or TCP and gives you channels, direct messages,
a node map, radio settings and repeater administration.

## About this manual

These pages describe Offband MeshCore 1.8.0. The screenshots are from Android;
the desktop apps use the same screens and settings in a wider layout. Some
features depend on your radio's firmware, and a page says so where that applies.
For the radio itself, see the [Offband firmware manual](https://docs.offband.org/firmware/).

The manual is maintained with the app's source code and is corrected as the app
changes. If a page doesn't match what you see, please
[report it](https://github.com/OffbandMesh/meshcore-client/issues/new/choose).
